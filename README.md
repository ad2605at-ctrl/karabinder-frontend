# Karabinder

名刺交換のときの会話を相手の名刺に紐づけ、後日連絡をするときや打ち合わせの前に見返すためのスマホアプリです。Expo SDK 58、React Native、TypeScript、Expo Router を使用しています。

## 開発版の起動

Node.js 24 と npm を使います。リポジトリを取得し、PRの作業ブランチに切り替えてから、プロジェクト直下で実行します。

```sh
npm ci
npm start
```

PCとスマホを同じネットワークに接続し、SDK 58 に対応する Expo Go でターミナルのQRコードを開いてください。Webで画面の流れだけを試す場合は、起動後に `w` を押します。カメラ、画像選択、録音、音声再生の確認にはスマホを使います。

## 試してみる

1. 初回は架空の名刺が3枚あります。「灯台」で会社名を、「試作品」で複数人と話した内容を検索できます。日付は画面に表示される `YYYY-MM-DD` 形式で検索できます。
2. 「名刺を登録」で氏名・会社名を入力します。スマホでは名刺の撮影や写真の選択もできます。保存すると詳細画面が開きます。
3. 「会話メモを追加」で参加者を選び、メモを入力します。スマホでは相手の了承を得て録音を開始し、「録音を終了」の後に保存してください。
4. 一覧で別の参加者の名刺を開き、同じメモが表示されることを確認します。「メモを編集」で本文を変更すると全参加者の履歴に反映されます。
5. アプリを開き直し、名刺・写真・メモ・録音が残っていることを確認します。

記録は端末のアプリ領域に保存します。ブラウザで試したデータはそのブラウザに保存されます。音声の文字起こし、OCR、要約、クラウド同期は今後の連携対象です。

## バックエンドとの接続

画面は `src/data/store.tsx` を通じてデータを読み書きします。名刺と会話は別のレコードで、一つの会話が複数の名刺IDを参照できます。バックエンド担当者と FastAPI の OpenAPI 定義を確認した段階で、一覧・詳細の取得、メモの保存、画像・音声の送信を順に接続します。端末内ファイルの名前はローカル表示用です。

## 検証

```sh
npm run typecheck
npm test
npx expo export --platform all
```

各機能は作業ブランチからプルリクエストを出してレビューします。
